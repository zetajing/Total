# S7 PLC 字符串触发记录器

双击 `S7触发记录器.exe`，检查 CPU、Rack、Slot，点击“开始记录”。默认 IP 为 `192.168.0.50`，CPU 为 S7-1200，Rack=0、Slot=1。S7-1500 通常也用 0/1；S7-300 常用 0/2，以现场硬件配置为准。

- 每 100 ms 发起一次读取：`DB2001.DBX1404.6`。
- 首次读到 TRUE 时，读取 `DB2001.DBX314.0` 的 `STRING[50]` 并记录一次；持续 TRUE 不重复记录。读到 FALSE 后重新允许触发。
- 启动/重新点击“开始记录”时若已经为 TRUE，也记录一次。通信重连保留本轮触发状态。
- STRING 地址是字节 314 的字符串头；共读取 52 字节，314 为容量、315 为实际长度、316 起为内容。不是从 314 直接取 50 个字符，也不是 WSTRING。
- 自动按天保存到程序旁的 `记录\记录_yyyy-MM-dd.csv`，UTF-8 BOM 编码，包含电脑本地时间和字符串。空字符串也记录。Excel 可以打开；字符串含换行时，一条记录可能跨文本行。
- 界面显示本次运行最近 1000 条，CSV 保留全部记录；发生文件写入错误立即停止并显示原因。
- 读取异常显示错误并每秒重连，只读 PLC，不写入或复位触发位。

100 ms 是软件轮询节拍，受 Windows 调度、通信耗时影响。PLC 应先更新字符串，再置位触发，并保持足够长时间；两次事件之间也需要保持 FALSE 供程序采样。短于采样间隔的脉冲、断线期间发生的事件、字符串在读取期间发生的修改，无法由这个只读程序保证捕获。程序没有写入 PLC 的确认握手，也不保证跨程序重启去重。

使用绝对 DB 地址前，需在现场确认 DB2001 的偏移与 STRING[50] 定义；S7-1200/1500 按设备要求开放外部 S7 访问（通常需允许 PUT/GET 并使用非优化 DB）。本工具不会修改 PLC 配置。S7 STRING 使用通信库默认编码，若现场字符串包含中文，应先确认 PLC 使用的编码。

开发源码位于 Total 仓库 `S7TriggerRecorder` 项目，直接使用现有 `InduLink.Protocols.S7` DLL（底层 S7.NetPlus）。桌面发布包为 Windows x64 自包含版本，无需另装 .NET。

发布命令：

```powershell
dotnet publish S7TriggerRecorder/S7TriggerRecorder.csproj -c Release -r win-x64 --self-contained true -o "$env:USERPROFILE/Desktop/S7触发记录器"
```

离线检查覆盖持续 TRUE 去重、FALSE 后重新触发、失败不消耗触发及 CSV 转义/按天保存；实际连接、触发和内容须以现场运行结果为准。
